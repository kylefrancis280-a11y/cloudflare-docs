Everything about the crew.

SHOTBREAK is fifty AI agents arranged as a real film production. This guide explains what each one does, how they talk to each other, and how to use them to break down a script in under two minutes.

Your first run

The shortest path to a full breakdown:

  1. Sign in at /app.html.
  2. Click New project or the gold banner at the top.
  3. Paste a script into the textarea. Anything from Fountain to a Google Doc paste works — the Script Normalizer scrubs the formatting.
  4. Click Run the crew. The 50-agent org chart animates as each agent completes its work.
  5. About 90 seconds later, you're scrolling through a complete, editable breakdown.

Every field in the breakdown is a text input. Rename a character, rewrite a shot's prompt, swap a location — the agents that depend on that field re-run in scope.

The 50-agent crew

Fifteen managers (Claude Opus) orchestrate. Thirty-five specialists (Claude Sonnet) execute. The split isn't cosmetic — it matches how a real film production divides labor between department heads and crew.

The crew is organized into five wings:

  • Directors — Vision, Story, Visual. Set the creative direction everyone else executes against.
  • Script Writers — Dialogue, Action, Prompt. Turn your script into clean pages and AI-ready prompts.
  • Characters — Visual, Psychological, Voice. Lock every character so they don't drift between shots.
  • Settings — Environment, Atmospherics, Dressing. Build the worlds your scenes live in.
  • Editors — Timeline, Pacing, Assembly. Cut, pace, and ship.

Chain of command

Every specialist has a manager. Every manager has a wing. Every manager reads the Vision Director's output before writing a single line. The orchestrator enforces this — specialists can't run until their manager has published a brief.

Example
How lighting decisions flow

Vision Director declares the project is neo-noir with a sodium palette. Visual Director writes the visual grammar: "motivated sources only, heavy shadow, single key." Atmospherics Builder reads both, then briefs Lighting Designer: "Per-scene key/fill/rim. Respect the sodium palette. Single motivated source per shot."

Lighting Designer writes the plan for scene 1. It flows back up through Atmospherics Builder to the Visual Director, who either signs off or issues a revision. Then the plan becomes part of the context every Prompt Smith call reads when writing the final video prompts.

How vision flows

Every agent call carries the director's context — the vision statement, the genre tags, the character bible, the location library — bundled into a single structured object. The same context reaches Prompt Smith on shot 47 that reaches the Cinematographer on shot 3.

This is why a character's look doesn't drift between scenes 2 and 9. The canonical description from Character Sculptor is in context for every prompt. This is also why the palette stays coherent — the Color Theorist's master palette is in context for every generation.

Which AI models power what

The crew uses two model tiers:

  • Claude Opus 4.7 — all 15 managers. Opus has the reasoning depth to reconcile specialists and make creative decisions.
  • Claude Sonnet 4.6 — all 35 specialists. Sonnet is fast and accurate for focused, single-role work.

For video and image generation (after the breakdown is done):

  • WaveSpeed for video — Kling 3.0, Google Veo 3, Minimax Hailuo, Seedance Turbo.
  • Flux for character reference images — Flux Schnell, Flux Dev, Flux Pro.

Script Drop-In

The Script Drop-In is the entry point for every project. One textarea, one Run the crew button. No wizard, no step-by-step, no drop-downs for tone or genre — the Vision Director infers those from the script itself.

Formats that work:

  • Pasted screenplay text (industry-standard formatting preferred but not required)
  • Fountain syntax
  • A Google Doc or Word paste with any amount of extra junk — the Script Normalizer handles it
  • Rough prose with scene headings (INT. / EXT.) and character cues

Editing the breakdown

When the crew finishes, you scroll through a document organized by scene. Each scene shows its shot list, and each shot shows its final prompt, characters in frame, duration target, lens, movement, lighting notes, sound direction.

Every field is editable inline. Click into it, change the text, click out. The crew recognizes which agents' outputs depend on that field and re-runs only those.

Renaming "Maya" to "Amara" doesn't just swap the string — Character Sculptor re-emits the canonical description with the new name, Prompt Smith rewrites every prompt that referenced her, Voice Builder updates her voice signature. In about 8 seconds.

Media Hub

The Media Hub generates the actual video clips from the breakdown's shot list. It's a separate surface because generation is slow (1-3 minutes per shot) and expensive (credits apply here).

From the breakdown, click Open Media Hub with these shots. Your shot list, prompts, character reference images, and model targets all travel with you. Generation can run in batches — queue 50 shots at once, check back in half an hour.

Editor & export

The Editor is a browser-based NLE (powered by FFmpeg.wasm) for arranging the generated clips. Drag clips from the Media Hub onto the timeline, trim, split, add transitions, render as MP4.

Once a timeline is saved, four editor-wing agents become available for review: Showrunner (Assembly Editor) for the full cut verdict, Editor for per-clip suggestions, Pacing Doctor for rhythm check, Transition Designer for cut-level recommendations.
