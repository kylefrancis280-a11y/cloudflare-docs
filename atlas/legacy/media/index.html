Where to focus first — the 80/20

  1. Lock the offer before spending a dollar. Hormozi: a great offer beats great targeting every time. Use the Grand Slam template in the Playbook.
  2. Ship the lead magnet — the Atlas Score Sample Report PDF (use ../media/sample-report.html when built, or borrow the page-3 of the playbook). Cold ad → email capture → drip → subscribe is more cost-efficient than cold ad → subscribe.
  3. Run 8 ad creatives in week one across two hooks (the "stop guessing" hook and the "8 AM EST briefing" hook). Kill anything below 1.5% CTR after $30 spent.
  4. Build the welcome email + week-1 drip before launch. Most retail-finance subs decide whether to keep paying inside the first 7 days.
  5. Track only three numbers daily: cost per lead (email captured), cost per subscribe (Stripe), trial-to-paid retention at day 30.

Printing & exporting PDFs

Single page → PDF

  1. Open any document above in Chrome, Edge, or Safari.
  2. Press Ctrl/Cmd + P.
  3. Set Destination to Save as PDF.
  4. Set Margins to Default and uncheck Headers and footers for a cleaner export.
  5. Save. The print stylesheet automatically converts dark theme → light, hides the nav, and inserts proper page breaks.

Whole kit → single PDF

From a desktop terminal with Chrome installed, run a one-liner per page (the headless flag works on macOS, Linux, and Windows with the appropriate path):

chrome --headless --disable-gpu --no-pdf-header-footer \ --print-to-pdf=atlas-marketing-plan-50.pdf \ https://atlasanalysis.net/media/marketing-plan-50.html

Repeat per page, then merge with any free PDF tool (Preview on macOS, pdftk on Linux, pdfunite).
