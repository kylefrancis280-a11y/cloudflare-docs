Creative · Gemini Image Prompts

Gemini Image Prompts
for Atlas ads

Drop-in prompts for Google Gemini (Imagen 3 / Imagen 4) to generate static ad creative for Atlas Analysis. Each prompt is paired with the format it's for (Meta feed, Reels cover, Stories, Google Display) and the on-image text overlay you'd add after generation.

Tool: Gemini (gemini.google.com) Format: copy → paste → generate Aspect ratios noted per prompt

How to use this doc

  1. Open Gemini at gemini.google.com.
  2. Copy any prompt below into the chat. Hit enter.
  3. If it generates the wrong aspect ratio, append "Aspect ratio 1:1" / "Aspect ratio 9:16" / "Aspect ratio 1.91:1" depending on placement.
  4. Generate 4 variations per prompt. Pick the strongest. Add the on-image text overlay listed under each prompt using Canva, Photopea, or Figma.
  5. Save as PNG/JPG. Upload to Meta Ads Manager / Google Ads.
Brand consistency suffix — append to every prompt "Atlas Analysis brand: deep navy and dark blue (#06080f, #0b0e18) backgrounds, electric blue (#4f8fff) and purple (#a855f7) gradient accents, sharp geometric triangle logo, subtle grid mesh texture, financial-platform aesthetic, professional and modern, high-end fintech UI feel."

Negative prompt — append if Gemini gives you junk

Avoid: stock photo people, generic business clipart, stock chart screenshots from Yahoo Finance, anything with text or letters baked into the image, blurry low-quality renders, cluttered backgrounds, neon/cyberpunk overload, cheesy lens flares, watermarks.

Gemini doesn't always honor "no text in the image" — generate 4 variations and pick the cleanest. Add headline text in Canva/Figma after, never let Gemini try to render the headline (it will misspell it).
